# DWK Life OS V2 变更说明

## 数据层

- 新增 `schemaVersion: 2`。
- 业务历史数据由单一 localStorage 对象迁移至分模块 IndexedDB 对象仓库。
- 新增 V1 原始备份、迁移状态、失败保护、V1 回滚入口、导入前自动备份和最近 5 次自动备份。
- 新增完整/模块 JSON 导出、导入预览、V1/V2 校验、同 ID 合并或完整替换。

## 产品功能

- 首页卡片配置、健康趋势和统计、财务预算与现金流、摩托车全周期记录、Java 学习日志与建议、点子加权看板、增强待办、周复盘 Markdown、统一提醒中心、隐私与数据页。
- 保留第一版账户口径、Java 路线、离职倒计时、恢复初始、加密密码库及各模块历史数据。

## 离线与界面

- Chart.js 4.5.0 本地化，不使用 CDN。
- 新增 `manifest.json`、SVG 应用图标和 `sw.js`。
- 深色控制台样式扩展到桌面和手机；长表单内部滚动且操作栏保持可见。
- Service Worker 使用网络优先、缓存回退，并在激活时删除旧版本缓存。

## 安全边界

- 不接入远程业务服务器，不自动上传个人数据。
- 健康只做记录统计，不做诊断。
- 财务预测明确标注为情景估算，不提供投资建议。
- 数据缺失时显示不足，不虚构结论。
