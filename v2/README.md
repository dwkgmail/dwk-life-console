# DWK Life OS｜丁文凯个人生活控制台 V2

DWK Life OS 是完全运行在浏览器本地的个人生活控制台。第二版在第一版原生 HTML、CSS、JavaScript 项目上增量升级，保留原有健康、财务、摩托车、Java 路线、点子、待办和加密密码库，并增加 IndexedDB、趋势图表、周复盘、提醒中心、完整备份恢复和 PWA 离线安装。

项目不连接业务服务器，不自动上传个人数据，也不提供医疗诊断、投资建议或高风险自动决策。

## 第二版主要功能

- 可配置首页：13+ 张实时卡片可隐藏、恢复和排序，保留第一版离职工作日倒计时。
- 健康：饮水、步数、运动、心情、CPAP、目标完成；7/30/90 天体重、周均体重、睡眠和 CPAP 图表及真实数据统计。
- 财务：可用资金与押金/应收款严格分离，预算、分类预算、固定支出、收入计划、大额标记、三情景现金流及四类图表。
- 摩托车：骑行、加油、故障、维修、保养、保险/年检和出发前检查，自动计算油耗、油费、里程与提醒。
- Java：路线、学习日志、自动时长、问题/代码/错误/解法、连续天数和单知识点学习建议。
- 点子：六维评分、加权综合分、自动排序和七阶段看板，不自动删除低分点子。
- 待办：日期、优先级、模块、预计/实际耗时、重复、完成时间、延期原因和多种视图。
- 周复盘：按日期自动汇总并手动复盘，可导出 Markdown。
- 提醒中心：页面打开时本地计算待办、保养、保险、体重、学习、预算和周复盘提醒。
- 隐私与数据：完整/分模块导出、导入预览、版本校验、重复 ID 合并、导入前自动备份、V1 恢复入口。
- PWA：离线缓存、可安装、Service Worker 自动替换旧版本缓存。

## 第一版数据迁移

首次打开 V2 时会检查 localStorage 的 `dwk-life-os-v1`：

1. 先把原始字符串保存为 `dwk-life-os-v1-backup-时间戳`。
2. 在 `dwk-life-os-v1-backups` 中登记备份索引。
3. 将历史数据规范化为 `schemaVersion: 2` 后写入 IndexedDB 数据库 `dwk-life-os-v2`。
4. 原 `dwk-life-os-v1` 键始终保留，不会因迁移成功或失败而删除。
5. 迁移失败时显示数据库初始化错误，原数据和迁移前备份均保留。
6. 可在“隐私与数据”页把任一 V1 备份重新迁移到 V2；恢复前还会自动备份当前 V2 数据。

密码库仍使用独立的 `dwk-life-vault-v1`，不会被迁移为明文。

## 数据存储

- IndexedDB：健康、账户/流水、摩托车、Java、点子、待办、周复盘、预算与计划等业务数据。
- localStorage：主题/仪表盘设置、迁移状态、迁移备份、最近的自动备份和加密密码库密文。
- JSON 备份含 `schemaVersion`、导出时间、范围和数据；完整备份还包含密码库密文。

清理浏览器站点数据会删除记录。请定期点击“完整备份”保存 JSON 文件。更换电脑时需手动导出和导入。

## 本地运行

PWA、Service Worker 和 IndexedDB 建议通过 HTTP 打开，不要直接双击 `index.html`。

```powershell
cd C:\Users\br153\Documents\dwk-life-console
python -m http.server 8080
```

访问 `http://localhost:8080`。macOS/Linux 可使用 `python3 -m http.server 8080`。

安装依赖、运行测试和构建：

```powershell
npm install
npm test
npm run build
```

Chart.js 已复制到 `vendor/chart.umd.js`，浏览器运行时不依赖 CDN。

## PWA 安装

1. 通过 `localhost` 或 HTTPS 打开项目。
2. Chrome/Edge 桌面端点击地址栏的“安装”图标，或菜单中的“安装 DWK Life OS”。
3. Android Chrome 使用菜单“添加到主屏幕/安装应用”。
4. iPhone/iPad Safari 使用“分享”→“添加到主屏幕”。
5. 首次在线打开完成缓存后，即可离线启动。

## 已知限制

- 所有数据绑定当前浏览器来源；`file://`、`localhost:8080` 和其他端口彼此不共享数据。
- 提醒仅在打开页面时计算，不是后台推送。
- 现金流是基于用户输入的情景估算，不代表确定结果。
- 周复盘缺失数据会显示“无记录/数据不足”，不会补造数据。
- iOS 对 PWA、存储配额和后台缓存的策略由系统决定。
- SVG PWA 图标受现代浏览器支持；少数旧平台可能不显示安装图标。
