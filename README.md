# DWK Life OS｜丁文凯个人生活控制台

一个完全运行在浏览器本地的个人生活管理控制台。项目仅使用 HTML、CSS 和原生 JavaScript，不需要安装依赖，也不连接任何在线服务。所有数据保存在当前浏览器的 `localStorage` 中。

## 功能

- 首页总览：体重、可用资金、离职工作日、摩托里程、趋势、收支、Java 进度、待办与副业点子
- 健康记录：增删改查，并自动计算体重变化、7 日均重、30 日变化
- 财务管理：账户余额、收支流水、分类统计、可用资金、押金及资金支撑月数
- 摩托车管理：里程、加油、保养、保险，自动计算平均油耗和保养剩余里程
- Java 学习：22 项预置路线与四种学习状态
- 点子管理：预置 8 个方向，支持完整编辑
- 待办事项：今天必须完成、有空再做、明天处理、已完成
- 数据管理：完整 JSON 导出、导入和恢复初始演示数据

## Windows 运行方式

### 方式一：直接打开

双击项目根目录中的 `index.html`。大部分现代浏览器均可直接使用。

### 方式二：启动本地服务器（推荐）

如果电脑已安装 Python，在项目目录打开 PowerShell：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

也可以使用 Windows 自带的 Python Launcher：

```powershell
py -m http.server 8080
```

## macOS 运行方式

### 方式一：直接打开

在 Finder 中双击 `index.html`。

### 方式二：启动本地服务器（推荐）

在“终端”中进入项目目录：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 数据说明

- 数据自动保存，无需点击额外的“保存全部”按钮。
- 数据仅保存在当前浏览器、当前设备中；清除浏览器站点数据会删除记录。
- 建议定期点击右上角“导出数据”保存 JSON 备份。
- 导入会校验文件格式，并在确认后覆盖当前数据。
- 直接双击与通过本地服务器访问时，浏览器会视为两个不同来源，两边的本地数据不会互通。

## 项目结构

```text
dwk-life-console/
├─ index.html
├─ README.md
├─ css/
│  └─ style.css
└─ js/
   ├─ app.js       # 应用入口、路由和事件
   ├─ data.js      # 初始数据与枚举
   ├─ storage.js   # localStorage、导入与导出
   ├─ ui.js        # 各页面渲染
   └─ utils.js     # 日期、金额、统计等工具
```

## 浏览器要求

推荐使用较新版本的 Chrome、Edge、Firefox 或 Safari。手机浏览器可直接访问同一局域网中的本地服务器地址。
